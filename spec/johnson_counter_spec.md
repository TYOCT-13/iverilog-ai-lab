# 4 位约翰逊（扭环）计数器

端口：`clk`、`rst_n`（异步、低有效）、`enable`、`q[3:0]`。

- 复位时 `q=0000`，且是**异步**复位：`rst_n` 拉低后不需要时钟沿就立即清零。
- `enable=1` 时每个时钟沿左移一位，并把最高位的**反相**反馈到最低位。
- 因为反馈取反，`0000` 不是吸收态：复位后自行进入
  `0000 → 0001 → 0011 → 0111 → 1111 → 1110 → 1100 → 1000 → 0000` 的 8 状态循环，
  序列周期正好 8 拍，`1111` 之后回到 `1110`（而不是继续全 1）。
- `enable=0` 时保持当前值：暂停期间不得移位，恢复后从暂停点继续。
