## 提交前实际检查

官方要求于2026-10-05核对，原链接见[共享规则数据](material_data.json)及[技术方案附录](technical_report.md)。通知截止2026-10-15 20:00北京时间。

1. 确认报名赛题与转赛道状态，核对真实队号，不填虚构编号或签署。
2. 导出技术PDF（≤10MB）、答辩PDF和一份合并佐证PDF，检查实际页数、可读性、字体和下载。
3. 网盘资料按官方格式“参赛团队编号-赛题名称-作品名称-XX（材料名称）”命名；系统单文件字段以系统要求为准，共享目录与文件均应含完整字段。队号和正式赛题名称未确认前用本版项目文件名，不伪造字段。检查正文、图片、页眉页脚及PDF元数据没有机构身份、标志或导师信息；技术源稿的匿名检查应覆盖学校/大学/学院等身份关键词，但不能据关键词误把普通技术术语改坏。
4. 如提供视频，录制真实过程和限制，MP4、3至5分钟、≤300MB。视频是可选佐证，不把未录制说成已完成。
5. 本地文件检查通过后，再由提交者实际上传或提供有效分享链接、提取码与有效期，使用干净浏览器验证下载，并保留系统回执。
