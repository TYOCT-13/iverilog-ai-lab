# v3报名与提交用文本

## 作品名称

ICARUS数字IP验证智能体

## 项目简介

面向数字IP开发中的边界和多周期验证，ICARUS通过DeepSeek API生成受约束的测试计划，由独立参考模型和Icarus Verilog逐拍判定，保存原始响应、用量及反例证据。支持案例与RTL上传、规则审查、验证循环和离线导出。新两模块受控批次108任务均实际执行，反馈策略检出11/12，固定12/12；36项正确控制无误报。作品未训练模型权重，当前实证限于内部合成模块，保留漏检和格式失败。

## 实际提交步骤

1. 确认系统中的AI＋集成电路赛题、真实队号和转赛道状态。名称限20字符、简介限300字符，本地计数通过后复制上述纯文本。
2. 使用本版实际导出并逐页检查的技术方案PDF（≤10MB）、答辩PDF和合并佐证PDF；源稿与PDF版本一致，旧v2不覆盖。
3. 网盘资料按“参赛团队编号-赛题名称-作品名称-XX（材料名称）”完整命名，共享目录和文件均适用。例如技术方案文件保留真实团队编号、系统中的正式赛题名称、上述作品名称和“技术方案”四个字段；队号未确认前不伪造。系统单文件上传字段以系统要求为准。正文、封面、图像与元数据按匿名要求检查，不写身份标识或虚构签署。
4. 如提供可选视频，录制真实操作，MP4、3至5分钟、≤300MB；未提供不写成已录。真人/H02是待补强证据，非本项目另加的官方硬必交条件。
5. 在截止2026-10-15 20:00北京时间前实际办理上传。若使用分享链接，核对提取码、有效期与干净浏览器下载，保存系统成功回执。本文件只提供文案和步骤，不表示已经提交。

格式与官方来源：[规则数据](material_data.json)、[主题赛通知](https://www.aicomp.cn/notice/4756.html)。
