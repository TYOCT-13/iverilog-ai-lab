# ICARUS 答辩 PPT（依据《简化版报告》重做）

## 这是什么

`ICARUS_答辩材料_修订版.pptx` 是在原 `../ICARUS_答辩材料.pptx` 基础上的重做版本。
原版内容以"防御性表述"（免责、保留、不声称、尚不支持…）为主，不适合答辩现场；本版
全部文字改按《简化版报告》重新撰写：正面陈述结论，数据与报告逐项对齐，冗余的技术免责
移入讲者备注。

- 版式语言完全沿用原版：深色封面 `#1C2023`、浅色内页 `#F5F7F8`、品牌青 `#00ABC8`、
  标题 34.5pt / 正文 19–20pt、页码 Bahnschrift、表格深色表头 + `#C9D3D8` 细线。
- 字体：中文 `Noto Sans SC`，数字/页码 `Bahnschrift`。
- 原生可编辑：无整页截图替代文字，表格与柱状图均为 PowerPoint 原生对象，20 页均带讲者备注。
