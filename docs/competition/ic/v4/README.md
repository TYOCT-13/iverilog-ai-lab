## 构建与检查

报告使用ReportLab和本机中文字体，`build_report.py`从正文JSON、附录JSON及图像生成PDF，使用pypdf检查页数、用pypdfium2渲染全部页面。`build_figures.py`生成14幅原创示意/统计图，其数据来自既有登记结果。实际截图来源与操作边界见[screenshots回执](screenshots/receipt.json)。`verify_materials.py`核对最终三个文件的页数、哈希、字体嵌入和本地来源链接；重建PDF后必须重新实际检查页面，不能沿用旧视觉回执。

PPT使用`@oai/artifact-tool`的ES模块构建、实际渲染和布局检查；运行方式及PDF导出限制见[presentation说明](presentation/README.md)。最终图像式答辩PDF经逐页渲染核对，PPTX未在原生PowerPoint中验证。

本轮不调用模型API，也不重跑功能实验；新增工具动作仅为文件与材料核对、文档渲染和界面观察中的null目标编译预检查。材料视觉检查为AI辅助检查，不能替代真人试用或独立人审。
