# 真人独立复核入口

本目录提供审核方法和空白记录，不表示已经有人完成审核。当前外部模块结果是开发者构造变体、运行工具得到的历史证据；代理自查不能补上真人独立审核。

| 要回答的问题 | 该做什么 | 入口 |
|---|---|---|
| 别人能否安装、操作并理解结果？ | 真人可用性试用，记录耗时、卡点、提示次数与原话 | [试用入口](../trial/README.md) |
| 基线、人工变体和判定是否有证据支持？ | 有 RTL / 验证基础的人逐条复核规格、差异和运行证据 | [独立复核指南](independent_review_guide.md) |
| 被测代码是否来自其他开源项目？ | 核对来源、许可、版本及文件哈希 | [外部模块记录](../experiment/external_results.md) |

这三件事不能互相替代。使用外部仓库模块不等于完成外部真人审核；有人试过界面也不等于其确认了 RTL 语义。

建议先找一位没有参与本工具开发、但学过 Verilog 和仿真的同学或老师做复核。若只能找到同团队的人，应选择没有编写该功能、变体及判据的人，说明关系，并称为“非作者复核”，不包装成完全外部审核。它不是认证，也不需要请竞赛官方评委。

审核人数和逐条记录是本项目的证据强化建议，不是声称官方规定必须有几名试用者或第三方审核机构。

交给审核人的文件：

1. [独立复核指南](independent_review_guide.md)。
2. 项目与源码、合约、计划、测试台及历史产物的冻结副本。
3. [整次复核记录模板](review_record_template.md)。
4. [逐条原始记录模板](variant_review_template.json)。

模板中的结论和身份确认必须由真人在实际核查后填写；不代签、不预填“通过”。公开姓名、原话、声音或原始录屏前，单独取得对应授权。录制方法见[录屏工作流](../demo/recording_workflow.md)。
