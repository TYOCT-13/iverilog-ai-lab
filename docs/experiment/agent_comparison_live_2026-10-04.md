## 可支持的结论与限制

本次反馈 Agent 检出 **4/8**，高于单次 API 和无反馈 Agent 的 **2/8**，但低于固定模板及随机策略的 **5/8**。因此不能写成“Agent 全面优于传统测试”。4 对 2 只是本次开发集观测，未通过多次独立重复排除远程模型随机性，也不能强因果归因为反馈机制。三个 API 策略在本轮 UART 两个缺陷上均为 0/2，且存在输出截断、动作校验错误及参考假警，均已保留在分母和状态表中。

本表只报告当前模块、缺陷和固定预算下的真实结果，不根据预期改写优劣。反馈 Agent 在发现反例后停止；它没有修改 RTL，也没有实现失败驱动修复。无反馈消融仍保留实际失败就停止的控制逻辑，只隐藏模型看到的上一轮 observation。

采样密度不相等：固定/随机计划归一化填满刺激周期，API 提案可能提前停止、预算超出而不执行或每段只检查边界；多轮重跑旧计划会重复消耗周期。相同周期上限不代表相同检查项数量，不能只凭本轮分数归因于反馈机制。

本轮只有开发集 1 次重复，提示词和固定模板与现有模块相关；规格仅有 common_cases 的一行说明与接口合约，随机基线不是协议感知随机生成器。没有独立留出集、置信区间、真人效果或第三方审核。本结果不足以证明通用性能提升或预测比赛奖项。

首次协议错误运行 `.iverilog-ai/agent-comparison-live-20261004` 完整保留，但不计入本文策略成绩。它使用了错误的隐式 Responses 协议，本次改为显式 chat_completions 并在新目录重新运行。首次失败不能被描述成成功，消耗也不包含在本轮 84 次预算内。
