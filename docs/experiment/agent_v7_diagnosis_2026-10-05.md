# v7 漏检与格式问题：完整组别只读诊断

本记录解释 v8 的修订依据，保持 v7 的登记、结果、主指标与全部原件不变。两位子代理分别核对格式和信用/仲裁全部任务，未调用 API 或新增 DUT 执行。这是工程诊断，不是真人试用、H02 或新的检出成绩。

## 动作格式

334 次请求中有 30 次普通 schema 拒绝：27 个决策添加了多余顶层字段，3 个决策给出超过 12 个向量（17、18、17，均在 SPI）。30 个被拒决策经当时冻结的校验器再核对，仍被拒绝。反馈、single、无反馈分别 13、5、12 次；请求位置 1、2、3 分别 17、7、6 次，分布于全部八类模块。

按安全错误位置计数为 29 个 extra_forbidden 与 3 个 too_long，共 32 条位置记录，不能写成 32 次失败请求。其中顶层 cycles 出现 15 次、sample_phase 出现 2 次。未知字段名不回显，安全提取记录与原响应来源摘要见[格式诊断](agent-v7-diagnosis-2026-10-05/schema-diagnosis.json)。字段层级错位是事实；提示词表述造成错位是推断，需新实验验证。

另有 4 次 fatal guard：2 个重复 JSON 键、2 个字符串无法可靠检查。原文当时已被安全阻断，只保留哈希、长度和固定错误码，不重建坏字符串或伪造更详细的根因，也不放宽为可重试。

## 信用控制与轮转仲裁

范围是全部 108 项登记任务：六策略各 18，其中 Agent 合计 54（36 缺陷任务、18 正确控制）。反馈组 18 条轨迹共 47 次请求，28 次携带前次 observation；这 28 次都没有真实端口过程样本，只有运行/检查/失败摘要和 unsupported 场景覆盖。

相反证据同样保留：反馈组 42 个实际 episode 的逐拍采样工件全部完整；single 的 16 个、无反馈的 36 个 episode 也完整。若已检出，failure_samples 可以包含少数实际输出，所以不能称反馈完全没有真实数据。可改进的缺口是未检出后模型缺少实际端口变化，无法据此安排下一次完整操作。

信用反馈九任务用了 119 刺激拍，其中八拍为额外显式复位；只有四项在正确规格的 0 边界继续消耗、三项在 7 边界继续归还。三个目标 B 的反馈都没有在 0 状态继续消耗。已有一个 reason 将前次状态当作可重放，但执行状态明确每 episode 独立复位，实际执行器始终遵守该约束。累计操作数不等于单个 episode 的连续可达路径。

仲裁反馈九任务用了 121 拍，其中 16 拍为显式复位；26 个 episode 全部独立自动复位。九任务都出现多请求，但没有一项连续保持同一竞争组合并保持 advance=0，也没有连续保持该组合并让 advance=1。单次竞争或单请求检查不能完整观察正确规格的跨拍优先级保持、推进与环回。

反馈总计 240 拍，少于随机的 288 拍，且 24 拍用于额外显式复位。预算、重复动作早停、格式错误及模型停止也影响探索，不能把低检出全部归因于端口摘要。逐项统计与完整依据见[子组诊断](agent-v7-diagnosis-2026-10-05/prior-diagnosis.md)、[汇总](agent-v7-diagnosis-2026-10-05/prior-summary.json)、[任务表](agent-v7-diagnosis-2026-10-05/prior-rows.json)和[决策表](agent-v7-diagnosis-2026-10-05/prior-decision-audit.json)。

## 由证据支持的修订

v8 从真实校验模型生成紧凑层级约束，明确 cycles/sample_phase 位于向量内部；连续相同输入可用 cycles 表示，保持向量上限。拒绝仍不执行，安全阻断规则不变。

同时加入通用的真实端口摘要：核验完成的进程、原始 stdout、采样工件及输入来源；确定性等间隔选点，保留位宽、X/Z 与省略数，不读取判据挑选样本。端口事实不替代功能覆盖，非旧四模块仍保持 unsupported。

规划文案强调独立 episode 重新从复位出发计算连续路径，观察到的末状态不作为下次初始状态。不把目标标签、私有见证、缺陷特定序列或历史成绩发送给 API。新增完整实验将保持 v7 的八模块成员、预算、基线和顺序；全部八模块已有实测暴露，不再称新留出。

是否降低拒绝、改善补测或超过随机，须以[新的完整事前方案](agent_feedback_study_plan_2026-10-05.md)执行后的全分母结果为准。原字节封装见[诊断回执](agent-v7-diagnosis-2026-10-05/receipt.json)。
