# 冻结后新增模块评测：事前方案

日期：2026-10-05。此文件在本批任何真实API请求之前建立。此前四模块的恢复轮、全部分母和失败继续原样保留。

## 问题与冻结边界

恢复轮反馈组23/24高于随机16/24，但只覆盖FIFO、UART、SPI及握手四个开发模块。新增两类不同接口的模块，检查相同Agent在此前开发集合之外能否提出有用激励。

Agent算法文件固定为 `f664d85c9204ffacb64c54feeb9e6dd13c87a34a` 中的v6版本，SHA `b3eca75bab345ef2b9d5d2ebd0280f9811bd37532fb979d2f8c5a4ac220ce5fe`；system提示SHA `8b5f844143e9c85052eee2398cf2f13c4840e3fc86e589ca9c48fc4304c7cb03`。设计新模块、建立判据之后不更改上述内容，不根据API成绩修改任务、提示或预算。模型权重由远程API提供；不是本地权重训练。

这是内部作者在程序冻结后设计的、模块集合互斥的合成留出。模型仅收到完整正确规格、合约、预算和允许的执行反馈；当前冻结Agent不把目标或正确参考RTL源码、路径和SHA放入请求状态。执行器在本地读取RTL供仿真和字节绑定。模型的预训练是否见过类似算法未知。本批不称外部独立盲测，不等于H02，不证明任意工业设计泛化。

## 固定任务与预算

- 两模块：`credit_guard`（3位饱和额度、同时申请释放保持）和 `rotating_arbiter`（4请求、轮转优先序、advance门控）。模块参数固定为空，合约及完整语义见新规格。
- 各含1正确目标与2单点缺陷，目标命名A/B/C；RTL源码、缺陷标签、预先人工witness与manifest说明不进入API消息，模型不会收到审核答案或正确参考RTL。
- 六组：fixed、random、protocol_random、single、feedback、no_feedback。3次重复，种子0/1/2；每组18任务，含12缺陷任务、6正确控制；完整批次108任务。12缺陷任务来自4个不同缺陷重复，不是12个独立缺陷。
- 所有策略每任务最多累计16激励周期，逐拍after检查全部输出；每实际episode独立从合约reset启动。single最多1请求/1轮，反馈及无反馈最多3请求/3轮；沿用冻结Agent每提案最多12向量、累计接受向量内部上限64，三种基线每计划也不超过12向量。16拍上限使累计64上限不会成为本轮瓶颈。初始reset与每轮正确参考审核周期单独记录，不混入16周期。
- 最多126真实请求，本批输入＋输出共享100万tokens；历史用量不扣新批次。拒绝动作和失败请求也计账，未知usage保守预留。4096输出上限、thinking disabled、nonstream、60秒超时，无自动网络重试。
- 冻结登记每行顺序、源文件、合同、规格、目标RTL、基线实现、判据与测试。先登记SHA和保存原字节，才启动API；完整批次只运行一次，不以选样或最好一次替换。

顺序为seed、variant rank（reference/B/C）、case；六策略按seed＋rank＋case循环轮换，避免始终先跑某个策略。API内部随机数不可配对，远端服务时间变化不能排除。

## 基线、判据与资格

fixed只按规格写边界输入：额度包含空/满/同时/保持，仲裁包含全请求轮换、advance=0保持、单请求及稀疏请求。random按合同所有数据输入独立均匀采样，共12段，前4段各2拍、后8段各1拍；段内保持输入，逐拍检查。protocol_random按种子选择规格事务顺序/请求集合，生成函数不读取目标RTL、variant、缺陷描述、witness或任何仿真结果。fixed和protocol_random将相邻相同输入合为持续向量，保持原始16拍序列；三组都恰16拍、每计划不超过12向量且期望为空，由独立参考模型赋值。该新随机分段与旧四模块每拍重新随机的基线不同，不把两批合并成一个随机检出指标。

Python判据按状态语义编写，正确RTL用另一种表达实现。请求API之前用实际Icarus检查正确目标对齐、复位、边界、随机序列及所有单点witness；完整原件另存，初次失败不覆盖。每API/基线实际执行的计划再在正确RTL重放；逐拍输出/实际stdout/合同和RTL/测试台/参考表SHA共同绑定，AI期望数值不裁决通过失败。

使用现有功能覆盖分析器，新模块返回unsupported/unknown，不为本轮新增定制覆盖提示。no_feedback隐藏DUT观察、计划错误和格式诊断；执行器的早停和剩余预算仍能透露流程信号，不称完全无信息因果控制。普通格式错误可在原请求预算内补提，重复JSON键等安全拒绝仍停止。

全部108行保留。缺陷检出必须有成功编译、真实执行、正确参考无告警及可复核不一致；正确目标告警、未执行、格式耗尽、超周期提案、传输或账本异常不移出分母。严格整轮资格由所有行的执行证据与登记原字节核验计算，不因检出率高而补成true。
