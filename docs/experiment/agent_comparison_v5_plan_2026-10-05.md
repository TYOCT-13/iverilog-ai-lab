# Agent v5 新执行方式评测计划

本计划在新API请求前保存。v4及更早实验原件不修改；本轮是开发集评测，不是真人或独立留出，不预设Agent胜出。

## 更改与对照

`--profile v3`统一使用逐拍参考期望：每个输入段内部每拍按独立参考状态推进并比较；输入计划不展开为超出schema限制的向量列表，不把末态期望重复每拍。所有参与的固定、均匀随机、协议随机和API策略均使用同一逐拍检查方式。

API策略显式选择`agent_plan_mode=independent`。每轮新计划由真实测试台复位后独立执行，不延续上一轮电路状态；旧计划、失败、实际执行周期和请求仍留在轨迹。兼容库默认append仍照实计算整计划重放开销，不能以少记周期制造提升。

合法JSON不等于合法接口。执行前预检自动时钟、端口、位宽、采样相位和周期；预检失败保留请求、用量、固定错误码，并在剩余请求内允许补提。没有仿真不生成round，不把失败视为参考通过，错误不删分母。

本轮同时改变提示词、补测调度和采样，不能把新旧成绩差异单独归因于模型、覆盖反馈或某一改动。已保存v4计划的零API重放仅用于诊断采样修复，不计作模型新的在线成绩。

## 预定范围与资源

- 四类内置默认参数模块，每类正确基线和既有清单前两个缺陷；缺陷8个，仍是已调试开发集。
- 策略为fixed、random、protocol_random、feedback、no_feedback，1次重复，共60个登记任务。每策略8缺陷和4正确基线；未选single或无覆盖消融，不补造其结果。
- 两个API策略每任务最多3请求，共最多72次；单次请求非流式、60秒超时、输出上限8192 tokens，DeepSeek Flash官方Chat接口显式thinking disabled。
- 原累计360请求约束继续：此前已知276响应，另1可能在途保守预留，合计277；本轮最多72，累计预留349，剩余11。无自动重试或换服务商。具体费用无账单保持未知。
- 搜索周期上限仍为FIFO160、UART512、SPI384、握手160。每轮复位和参考审核开销分别说明；所有实际执行刺激周期如实累加。最大轮数/请求数不等于必须用尽，实际检查数和周期另列。

## 执行与统计

源码提交、输入SHA、完整规格、配置、提示词指纹和设置在请求前冻结。代码运行期间不改。目录必须是新的，不覆盖旧结果。

记录完整60任务、每轮原件、检查密度、首反例累计周期、参考审核、requests/usage、预检错误和未执行。检出由真实仿真与正常参考审核复算，正确基线假警分列；无仿真仍保留分母，严格证据资格按已有规则认定。

相同周期上限不表示实际周期/调用/时间一致。最终检出率、首反例及实际成本一起报告；不选择更好的重复，不将离线重查与新API实验拼成一次成绩。若随机也达8/8，只能讨论有限样本的效率与稳定性，不声称检出率超过100%。
