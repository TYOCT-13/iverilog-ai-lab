## 首次失败与修正

首版第二次调用只留下 `ValidationError`，没有保存错误字段、完成状态或该次 token 用量，因此无法事后确认是具体字段不符还是输出截断。保留这一失败记录，不将其改写成成功，也不对缺少的用量作估计。

本轮补充了结构限制说明，要求简短理由和少量补测向量，提示词升至 v2。同时让结构校验失败保留安全诊断和可用用量，识别服务端明确标记的截断输出。网页 Agent 现在沿用用户设置的输出长度和超时；原来固定的 2048 tokens 上限会覆盖网页设置，此处已修正。

续跑使用 8192 tokens 上限。由于提示词与长度上限同时调整，本次成功不能单独归因于其中某一项。两次有效响应合计已记录 7,017 tokens；失败的那一次没有保存用量，这不是全部用量或实付账单。
