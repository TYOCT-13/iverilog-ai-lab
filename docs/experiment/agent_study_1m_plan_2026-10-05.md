# 每轮1M tokens：完整协议优先对照事前方案

用户已明确“Agent使用的token每轮限制在1m以内”；旧360次累计请求上限撤销。保守把一轮定义为一次完整登记评测批次，输入加输出合计最多1,000,000 tokens，不扣历史857,957。不会因余额不足自动新建一轮绕过上限；旧账、三重复15/24与六项选样4/5记录不覆盖。

## 成员与条件

四个默认参数开发模块，每模块清单前两个缺陷及正确参考，seed0/1/2；固定、均匀随机、协议随机、single、feedback、no_feedback六组，216登记任务。各组分母24缺陷任务（同8缺陷重复），另12正确任务。不是新模块留出或盲测。

共同累计激励上限FIFO16/UART48/SPI20/握手8，逐拍after检查、权威参考期望、独立自动复位。single最多1提案/1请求，feedback与no_feedback最多3轮/3请求，所有实际激励共享同一累计上限，不能每次重置刺激预算。参考审核周期另列。基线补齐到上限，API短计划不补齐，实际资源不完全相同。

理论请求上限252，实际可能因检出、模型stop、格式/预算拒绝、周期耗尽或token守门更少；252不是承诺全部能在1M内完成。按seed、变体序位（reference先）、模块排序，策略按seed+序位+模块的偏移循环轮换；固定后不根据中途成绩改顺序。

## 统一规格与比较边界

[规格渲染器](../../scripts/agent_study_specs.py)保留原四完整规格，恰好删一段旧长预算。state及执行器控制剩余周期/请求/round，不写死one proposal；强调完整通用协议操作：FIFO填满拒写读回、UART启动并观察完整发送到busy释放、SPI完成及恢复、握手接收反压消费。所有API策略共享相同文本，只按既有策略隐藏/提供真实执行反馈。

严格顶层action/reason/vectors及现有schema不放宽；不塞固定测试向量或expected，不将模型提案清洗后过关。API不看到变体名称、旧失败答案或本地报告。生产Agent/core、RTL与参考判据保持4d8eafb实现。优化同时包含预算澄清、格式强调和协议场景优先，不能归因单因素或宣称训练了权重。

主指标为每组24缺陷任务检出数；并集、各重复、动作合规、误报、周期、请求、tokens与耗时为次指标。反馈/无反馈首请求有随机差异，模型seed不配对；优势若有也只是本轮开发集描述，不能单独证明反馈因果。过早用尽周期可使反馈无机会补完整帧，必须另列真实rounds与首次检出。

no_feedback也隐藏纯输入预检错误反馈，不只是DUT观察和功能场景；执行器仍会按结果提前停止，后续请求是否存在可能携带残余信息。三组仍共享规格、实际周期限额和每次独立复位。比较的是整个既有反馈接口配置，不称只隔离某一种反馈信号。

## token守门与原件

[守门实现](../../scripts/agent_token_budget.py)由全部API组共享单个账本，在最终HTTP body形成后估算输入，预留`2×JSON UTF-8字节+4096框架余量+实际max_tokens`，原子保存再请求；响应有效usage按prompt+completion=total结算。缓存hit/miss是输入子集，不重复相加。未知/超时保留预留；异常usage保留并停止；实际usage超过预留如实记录并停止。预估是保守工程预留，不是精确tokenizer或服务商计费保证；实际用量以[官方usage说明](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)为准。

每请求非流式、thinking disabled、60秒、输出4096，上限真实进请求。DeepSeek Flash官方API，零本地权重推理。无自动传输重试。请求数只是理论252门禁，token限额为预算标准；到限保留token_budget/token_accounting_error任务及全部216分母，零API基线仍可继续。
