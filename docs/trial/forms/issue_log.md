# 试用问题跟踪（空表）

本表只记录真实反馈关联的问题，不提前填入成功评价。自动测试发现的问题可另建记录，并明确来源为测试，不能算真人反馈。

| 问题 ID | session_id / 任务 ID | 严重度 | 实际现象 | 预期行为 | 重现步骤 / 证据 | 是否有临时绕过 | 状态 | 修复版本 / commit | 复测 session_id 与结果 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | | |

严重度：blocker（任务无法继续）、major（有明显障碍或需绕过）、minor（不阻断的小问题）、docs（说明缺失或难理解）。状态可用待确认、已确认、处理中、待复测、已验证、暂不处理；暂不处理写明理由。

修复后不能直接改旧试用的结果为“完成”。保留原记录，新的真人复测建立新 session_id，并关联前次会话。同一个匿名代号多次试用仍算一个人。引用原话前检查对应会话的匿名引用授权；录屏授权与引用授权互不替代。
