# T02｜运行一个内置案例

标签：核心流程 / 离线 / 结果理解。状态：**任务方案，尚无真人执行记录**。

## 参与者任务

**目标**：完成一次内置案例测试，向另一位同学说明这次运行得到了什么信息。

**前提**：网页可打开，Icarus 可用；不需要看 RTL、不需要 API 密钥。组织者指定一个内置案例，例如“模十计数器”，并在记录中固定名称。

**时间盒**：8–10 分钟。

**步骤**：

1. 在顶部选择“验证一份 RTL”，进入“工作台”。在“选择设计”的“案例”中选组织者指定的案例。
2. 打开“工具设置 → 测试计划与模型”，把“生成方式”设为“离线模式”。回到“工作台”。
3. 在“运行测试”点击“生成测试计划”。观察页面变化，可以展开“测试计划与规则”。记录生成计划耗时。
4. 点击“运行测试计划”。结束后进入“测试结果 → 结论”，用自己的话分别描述工具运行情况和设计检查结论。
5. 在“波形”页签寻找本次波形信息；若有“选择时间范围”，尝试展开并使用“读取波形”。不要求安装 GTKWave。
6. 找出“期望值来源”“计划执行情况”以及未执行的证据层信息。说说哪些信息能帮助你判断结果、哪些不明白。需要时可查“使用手册”。

**观察与证据**：保存结论区和一处你实际查看的证据；记录计划生成、运行、查找证据各自耗时。回答：“你现在会怎样向别人解释这次结果？还有什么想查但没找到？”保留不确定的原话。

**终止与支持条件**：找不到下一步超过 2 分钟可以求助；生成或运行报错后先保存提示，不连续重复点击。单次运行等待超过 2 分钟请交由组织者检查。没有波形时记录页面说明，不另装工具来完成本题。
