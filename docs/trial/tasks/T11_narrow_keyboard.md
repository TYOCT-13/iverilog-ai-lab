# T11｜窄屏阅读与键盘操作

标签：可选 / 手机阅读 / 键盘可达性。状态：**任务方案，尚无真人执行记录**。

## 参与者任务

**目标**：在较窄的画面或不用鼠标时，找到操作入口并理解一份已有结果。

**前提**：组织者提供已打开的离线网页会话，最好已有 T02 结果。使用真实手机时由组织者提供已确认可访问的测试地址；本卡不要求你改变防火墙或暴露本地服务。桌面模拟与真实设备分开标记。

**时间盒**：8–10 分钟；选择窄屏或键盘其中一条即可，两条都做时分别计时。

**步骤 A：窄屏或真实手机**：

1. 记录设备、浏览器、方向、缩放比例与视口尺寸。桌面模拟可选 390 × 844；平板补测可选 768 × 1024，不要冒充真实手机结果。
2. 找到页面导航，依次打开“工作台”“工具设置”“使用手册”，再回工作台。记录第一次找到每个入口的过程。
3. 在当前结果中找到“结论”“波形”“导出证据”，读出一次结果的含义。观察是否必须左右拖整页、文字是否被遮挡、按钮是否容易点错。
4. 若组织者已准备案例，可以生成并运行一次离线计划；纯阅读角色无需安装工具或上传文件。记录未覆盖的操作。

**步骤 B：桌面键盘**：

1. 回到普通桌面窗口，从浏览器页面起点开始，使用 Tab、Shift+Tab、方向键、Enter/空格寻找导航和主要控件；记录使用了哪些键。
2. 不用鼠标尝试进入“工作台”，选案例、生成计划、运行计划，并到“结论”或“导出证据”。若弹出选择框，可用 Escape 尝试关闭。
3. 将浏览器缩放到 200%，尝试再次找到当前结论与页面导航。观察焦点是否可见、顺序是否能理解，有没有出不来的区域。

**观察与证据**：一段短录屏或问题截图，注明设备/视口/缩放和操作路径；记录第一个不能继续的位置。指出你无法读到的文字或点不到的按钮，而不只写“移动端不友好”。

**终止与支持条件**：找不到焦点或连续 2 分钟无法继续时停止该分支，记录最后能操作的位置后求助。可以用鼠标退出，但要记录。无需为试用安装额外无障碍软件；若本来使用读屏器，可自愿作为独立扩展记录。
