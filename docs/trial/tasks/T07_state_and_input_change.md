# T07｜中途离开与更换输入

标签：核心流程 / 连续操作 / 状态理解。状态：**任务方案，尚无真人执行记录**。

## 参与者任务

**目标**：模拟工作中切页、改设置、换文件后继续操作，判断页面上的结果属于哪一次输入。

**前提**：T02 已运行并得到结果；保留本次浏览器会话，不按 F5、不关闭标签页。基础任务只改变本地设置，不调用 API。

**时间盒**：6–8 分钟。开发者可增加最后的自定义输入扩展。

**步骤**：

1. 记录当前案例、计划是否存在、结果概要与运行 ID（可从“运行详情”查找）。
2. 在“工具设置 → 测试计划与模型”把“请求超时（秒）”改为另一可选值；保持“离线模式”。依次查看“使用手册”“规则审查”，然后回“工作台”。
3. 观察原输入、计划、结果是否还在；再回工具设置，记录刚才修改的数值。描述哪些内容你希望保留，哪些不希望保留。
4. 回工作台，在“案例”选择另一个内置案例。**先不运行**，记录此时计划、按钮、结论与导出区各显示什么；说明你如何判断结果是否属于新案例。
5. 为新案例生成并运行计划，确认自己能区分两次运行。记录遇到的任何含混提示。
6. 可选开发者扩展：完成 T04 后，修改“接口定义 JSON”，点击到文本框外让编辑生效；先不重新校验，观察计划/结果，再重新校验。或移除旧上传文件，上传同名但内容不同的副本；每次只做一种变化并记录。

**观察与证据**：至少保存切页前、普通切页后、更换输入但尚未运行时三张截图；记录输入名称、运行 ID和你对结果归属的判断。发生意外后不要立即刷新掩盖现场。

**终止与支持条件**：找不到原页面可求助；若仍显示旧文件的结果且容易误认，先截图并停止用该结果作决定，交给组织者复核。关闭浏览器或刷新造成的状态变化另记，不混入普通导航测试。
