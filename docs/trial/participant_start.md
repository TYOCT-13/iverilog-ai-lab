# Icarus 智测试用说明

请按分配的任务使用工具，记录实际发生的事。能完成、看不懂、报错和中途停止都有记录价值。无需证明工具好用，也无需猜作者希望看到什么结果。

## 选择运行方式

**已有网页**：打开组织者提供的地址。`127.0.0.1` 或 `localhost` 只表示你正在使用的这台设备，不能让另一台手机访问组织者电脑。打不开就记下现象并联系组织者，不用自行改路由、防火墙或公开服务。

**需要自己克隆和安装**：按[2026-10-08复现指南](../reproduce_current.md)记录会话、克隆GitHub并固定f7867db，再做T01。本轮优先使用Python3.12、uv锁依赖和Icarus，安装可能需要联网，离线操作不需要模型密钥。拿到代码压缩包时记录其版本与校验值；不要自行假填commit。安装卡住可以停止，改用组织者主机完成其他任务，两种模式分别记录。

**手机或平板**：使用组织者已准备好的受控访问地址。若只是电脑浏览器缩窄窗口，请记录为电脑窄屏检查，不能算真实手机试用。

## 任务怎么做

1. 打开分配的任务卡并开始计时。未计时就填写未记录，不补猜精确秒数。
2. 按自己的理解操作。需要帮助就提出，并记录得到的提示；协助完成不能写成独立完成。
3. 保存对应任务的截图或运行导出文件，尽量带错误原文或运行 ID。
4. 达到目标后停表；卡住超过时间盒可以停止，写清卡在哪一步。
5. 分别写事实和看法。例如先记“点击后等待 30 秒，没有新状态”，再记“我不知道是否还在运行”。

工具发现设计错误，可能正是任务完成。任务达到目标记 completed，部分完成记 partial，被阻塞记 blocked，决定不做已分配任务记 skipped，并写原因。没分配的任务不用填。

## 交回什么

交回填写的 Word 或 Markdown、截图与运行导出文件，以及同意保存的原始录屏。可请组织者帮助转录，但要核对是否保留原意。交回前检查没有密钥、私人聊天或无权提供的项目源码。

如果承担完整工程复现，另交[复现记录表](forms/reproduction_record.md)、终端原件及CLI运行产物。记录本人实际版本、是否接受帮助、首次失败和复测；普通网页试用无需强行运行进阶源码或技能门禁。
