## 汇总方法

```powershell

python scripts/summarize_trial_feedback.py docs/trial/feedback-*.json
```

脚本会做三件事：校验每份反馈的结构、把关键数字汇总成表、把问题按严重度排序。
**它不会美化措辞**——原始记录保留在各份 JSON 里。
