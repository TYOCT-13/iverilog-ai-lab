## 指标

| 指标 | 当前值 | 统计边界 |
| --- | --- | --- |
| 独立试用人数 / 会话数 | 待收集 | 同一人的复测不增加人数；团队成员与外部参与者分列 |
| 首次试用 / 复测 | 待收集 | 两轮分开，保留首次失败 |
| 各任务完成 / 部分完成 / 卡住 / 跳过 / 缺记录 | 待收集 | 分母为该任务被分配的次数，缺记录不消失；未分配不算失败 |
| 无协助完成数量与比例 | 待收集 | 完成且明确记录 0 次帮助才计入；未知协助次数不按 0 |
| 各任务完成用时中位数 | 待收集 | 仅已完成且计时实测的任务，报告样本量；含等待、重试和求助，估计用时单列 |
| 安装与环境问题 | 已登记命令缺失、下载失败、PATH及工具路径问题 | 用户明确说明为另一台复现电脑；处理建议与用户后续输出分别记录 |
| 参与者对结果的理解 | 待收集 | 保留原话及上下文，不预设认可或满意的答案 |
| 公开摘要样本范围 | 待收集 | 仅同意匿名引用的记录，注明被排除数量及分母变化 |

任务完成描述的是参与者是否达到观察与操作目标。被测设计出现 FAIL，不自动等于真人试用失败；编译不通过也不能直接算成设计功能缺陷检出。

## 汇总方法

在项目根目录执行，输入必须来自真实原件的转录：

```powershell
python scripts/summarize_trial_sessions.py .iverilog-ai/trial-sessions/round-1/*.json
python scripts/summarize_trial_sessions.py .iverilog-ai/trial-sessions/round-1/*.json --public
```

脚本校验结构、区分模板和真人声明、汇总任务状态与计时，但无法认证“此人是否真的试用”。组织者必须核对原件和授权。输出不会自动写入本页，也不会替参与者确认意见；收到真实材料后，另存带日期的摘要并在这里链接。
