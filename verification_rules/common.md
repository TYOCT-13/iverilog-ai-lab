# Icarus 智测通用规则

1. 只能使用 DUT contract 中声明的端口名、方向和位宽。
2. 输入值必须符合端口位宽；1 位信号只能取 0 或 1。
3. 时钟由 testbench 自动产生，不得作为普通输入向量驱动。
4. 每个向量名称必须唯一；每个检查项必须提供 expected。
5. reset 只能使用 schema 规定的字段，不要把端口名写成额外字段。
6. 不得输出 Verilog、SVA、shell 命令或文件路径。
7. 不确定的行为必须写入 assumptions，不得伪造确定结论。
8. 时序逻辑使用非阻塞赋值，组合逻辑使用阻塞赋值；综合 RTL 不使用 `#delay`。
9. 组合逻辑提供默认赋值；状态机包含安全 `default` 分支。
10. 多时钟设计必须明确时钟域；单比特 CDC 使用同步器，多比特 CDC 使用握手或异步 FIFO。
11. 仿真、综合、时序和硬件状态必须分开报告，不能用仿真通过推断综合或上板通过。
12. 测试台必须输出结构化结果，并保留失败周期、输入、期望和实际输出。
