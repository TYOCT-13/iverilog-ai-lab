# RTL 缺陷基准

每个案例提供一个正确参考和若干可编译、可触发的独立缺陷版本。运行对应 `tb/` 自检台时，参考版本应输出结构化 `IVERILOG_AI_RESULT` 全部通过；替换同名模块为缺陷版本后应至少出现一个 `ok=false` 反例。

当前基准共 4 类、50 个缺陷：模十计数器（12）、交通灯（11）、简单 ALU（14）和可重叠 101 序列检测器（13）。`benchmarks/manifest.json` 记录每个缺陷的触发条件、期望行为和 testbench 映射；`scripts/run_benchmark_matrix.py` 可一次性运行完整矩阵并生成检测率摘要。固定矩阵最近一次实跑为 50/50 检出、参考误报 0、不可判定 0。
